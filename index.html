Aperçu

Ce réglage général s’applique à l’aperçu, à toute la bibliothèque et aux exports JPG.

Cliquez sur un élément de la carte (titre, nom, rôle, faction, description, statut, ID) pour le modifier directement ici ; les champs de gauche restent synchronisés.

Partager mes cartes

Connectez-vous pour créer un code de partage.

Un code donne un accès en lecture à une copie des cartes du dossier choisi (sous-dossiers inclus). Toute personne qui possède le code peut les voir et les importer. Vous pouvez mettre à jour ou révoquer un partage à tout moment.
